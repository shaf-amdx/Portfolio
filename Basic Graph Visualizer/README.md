#Graph Visualizer

Generates graphs of basic math functions.

##Features

 Uses the 'math' module to compute mathematical values of a function.
 Plots the x and y coordinates at specific points using the 'turtle' module.
 Helps the user visualize the behavior of a mathematical function.

##Note

 Creates an approximation of the graph of a function.
 Only basic functions like trigonometric and exponential functions are supported.
