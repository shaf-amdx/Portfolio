#Python Project Portfolio - Shafeeq Ahmed

This repository contains a collection of personal Python programs that demonstrate algorithmic thinking, problem-solving, and experimentation in personal programming skills using various Python modules and data structures.

##Projects

  1.**Barcode Manager**: Generates non-traditional barcodes using custom inputs and personally designed algorithms.

  2.**Math Function Visualizer**: Helps the user visualize the behaviour of math functions by plotting specific points on a graph.

  3.**Block Game**: A small interactive game that includes collision detection and block placement algorithms with score tracking mechanisms.

  4.**Text Drawing Tool**: An interactive graphic platform where plain text input is converted into a graphical representation of text, which simulates writing on a blackboard.

  5.**Tic Tac Toe**: A classic two-player game built for users to play against a hardcoded bot.
